DESIGN MISTAKES:
✗ Using #111111 or #0B0B0B instead of the navy 
  (#060E1A / #0A1628). Double-check all hex codes.

✗ Using border-radius 8px, 12px, or 16px anywhere. 
  Every element: 2px ONLY.

✗ Adding ALL CAPS section labels (like "OUR SERVICES").
  This was explicitly prohibited. Use sentence case.

✗ Adding "→" arrows to button text.
  Every button must end with the last word, 
  no arrow icon or symbol after.

✗ Making the marquee text appear in ALL CAPS.
  It should be title case as written.

✗ Using yellow (#FFD700) instead of gold (#C9A96E).
  These look completely different. Use exact codes.

✗ Using generic template sections that weren't 
  specified. If a section wasn't in this brief, 
  it should not be on the site.

✗ Not implementing the staggered why-us stat cards 
  (card 2 down 2rem, card 3 up 2rem). This is what 
  makes it look designed vs template.

✗ Making all portfolio items the same size instead 
  of the asymmetric 7-5 / 4-8 split.

✗ Making the services sidebar not sticky. It MUST 
  be position:sticky, top 6rem on desktop.

FUNCTIONALITY MISTAKES:
✗ WhatsApp number format. 
  MUST be: https://wa.me/91XXXXXXXXXX
  NOT: https://wa.me/+91XXXXXXXXXX  
  NOT: https://wa.me/0XXXXXXXXXX
  Test every single WhatsApp link before delivery.

✗ Counter animation firing on page load instead of 
  when the stats bar scrolls into view. 
  Must use IntersectionObserver with threshold 0.5.
  Must fire ONCE only (unobserve after trigger).

✗ All services open in accordion by default. 
  ONLY the first item (Modular Kitchen) is open. 
  All others closed. Set class="open" in HTML on 
  first item, not in JavaScript.

✗ Mobile menu not closing after clicking a link. 
  Every mobile nav link MUST call closeMobileMenu().
  Also add event listener to backdrop click.

✗ Nav transparent on light-background pages (About, 
  Blog, Contact). These pages start in solid state. 
  Add body class "light-page" and CSS:
  body.light-page .nav { 
    background: rgba(248,245,240,0.96);
    backdrop-filter: blur(16px);
  }

✗ Announcement bar pushing nav down but nav not 
  recalculating top offset after bar is closed.
  Use JS to set nav top based on bar height.

✗ Copyright year hardcoded as 2024 or 2025.
  MUST be dynamic JavaScript (shown earlier).

✗ Form submitting but no WhatsApp opening AND no 
  redirect to thank-you page. Both must happen.

✗ Social media footer links pointing to 
  platform homepages (instagram.com) instead of 
  the actual business profile pages. 
  Set every link to the exact profile URL provided.

✗ Google Analytics code missing, wrong, or firing 
  only on some pages. Must be on EVERY page 
  including thank-you, 404, blog articles.

✗ Schema markup has JSON syntax errors 
  (missing commas, unclosed brackets). 
  Validate at: https://validator.schema.org/

✗ Image alt text left as filename.jpg or empty.
  Every image needs descriptive alt text as specified.

✗ Canonical tags missing on service pages and 
  blog articles. Missing canonicals = duplicate 
  content risk.

✗ Hero text overflowing or breaking badly on 
  360px wide Android phones. Test specifically at 
  360px width. Use clamp() for all heading sizes.

✗ Sticky mobile bottom CTA bar not being built 
  at all. This is a critical component. If absent, 
  request it immediately.

✗ Portfolio filter buttons built but filter 
  not working (items don't hide/show on click).
  Filter must actually work using CSS classes 
  and JavaScript toggle.

✗ All images same dimensions. Hero, portfolio, 
  blog thumbnails all need different sizes as 
  specified. Using same image everywhere 
  makes it look template-built.

SEO MISTAKES:
✗ All pages have the same meta description.
  Every page MUST have a unique meta description.

✗ H1 tag missing or used multiple times on a page.
  Exactly ONE H1 per page, always.

✗ Blog article pages missing Article schema markup.

✗ Service pages not indexed because they're

✗ Sitemap not submitted to Google Search Console
